# API Response

相關 API 調用後都以 JSON 格式返回，返回格式如下：
{ "isSuccess": true or false, "data": API 返回的資料, "errorCode": 錯誤代碼, "message": 若調用失敗，相關的錯誤信息 }


# ErrorCode List

## AlphaSolution 的 Error Code

- 9999: 系統錯誤
- 9998: 參數錯誤
- 9997: CEM API 錯誤

## 查詢賬單

2. 查詢賬單資料 Get Bill Information

    - URL: /api/bill/{contract_no}/ai/{lang}
    - URL parameters:
        - contract_no: 合約號碼
        - lang: zh|en|pt
    - Query parameters:
        - level: 可選，1|2|3|5，預設為 1
