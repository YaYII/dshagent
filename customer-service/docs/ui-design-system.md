# 客服前端设计系统

游客端页面（`web/guest/index.html`）的视觉规范。改样式前先读这一页，避免又退回
「一堆默认值」的状态。

## 1. 设计取向

参考两个站点的设计语言：核點設計 NUDOT（流体字阶、字距阶梯、编辑式排版）与
Studio Loop（微交互、动效节奏）。落成三条原则：

1. **深色为默认，一键切浅色**（header 右侧圆形按钮，选择记在 `localStorage`）。
2. **只用系统字体**。离线部署 + iframe CSP 不允许外部字体；观感靠字阶、字距、
   字重与留白，而不是靠换字体。
3. **深度靠发丝线 + 分层底色 + 内高光**，不用重投影。深色主题下大面积阴影会显脏。

生成内容（mermaid 图、`image` 图、`html` 卡片）统一走**纸面版画**：深色界面里放浅色
图版（`--paper`）。这是有意的对比，不是没适配深色。

## 2. Token

全部定义在 `:root`，浅色主题在 `:root[data-theme="light"]` 覆盖同一套名字。

| 类别 | Token | 说明 |
|---|---|---|
| 画布 | `--bg` `--bg-2` `--panel` `--panel-2` | 四级层次，从页面底到内容面 |
| 文字 | `--text` `--text-2` `--muted` | 正文 / 次要 / 弱化（**小字只能用前两级**） |
| 结构 | `--hair` `--hair-2` | 发丝线；结构靠它而不是靠边框块 |
| 主色 | `--accent` | 填充用（按钮底、渐变），上面压 `--accent-ink` |
| 主色文字 | `--accent-text` | **主色当文字色时必须用这个** |
| 纸面 | `--paper` `--paper-ink` `--paper-hair` | 生成内容的图版 |
| 字阶 | `--t-meta` `--t-sm` `--t-base` `--t-lg` `--d-2` `--d-1` | `clamp()` 流体，不靠断点跳变 |
| 字距 | `--track-display` `-tight` `-ui` `-label` `-meta` | 大标题收紧、小标签放开 |
| 行高 | `--lead-display` `--lead-tight` `--lead-body` | 0.94 / 1.35 / 1.72 |
| 间距 | `--s1`…`--s8` | 4 的倍数，只用这几档 |
| 圆角 | `--r-xs` `--r-sm` `--r` `--r-lg` `--r-pill` | |
| 动效 | `--ease` `--dur-1/2/3` | 统一缓动与三档时长 |

### 为什么 `--accent` 与 `--accent-text` 必须分开

同一个青绿，当**填充**够用、当 **10px 小字**就不达标：

| 场景 | 颜色 | 对比度 |
|---|---|---|
| 白字压 `#0d9488`（浅色填充） | | **3.74:1** ✗ |
| 白字压 `#115e59`（压深后） | | 7.58:1 ✓ |
| `#0d9488` 当小字压在象牙底 | | **3.46:1** ✗ |
| `#0b6b60` 当小字压在象牙底 | | 5.91:1 ✓ |

深色主题同理：`#14b8a6` 当填充配墨字 6.80:1 ✓，但当小字要换 `#5eead4`（13.5:1）。

## 3. 可计算的验收（不靠肉眼）

页面改完必须跑 `ui-audit`（在 `/home/as-workstation01/Documents/project/Chrome/`）：

```sh
node /home/as-workstation01/Documents/project/Chrome/ui-audit.mjs
```

它做四件事，任何一项不过都要修：

1. **对比度**：遍历所有可见文字节点，正文 ≥4.5:1、大字 ≥3:1。
   背景解析必须同时处理**渐变**与 **alpha**——只读 `backgroundColor` 会把
   「墨字压青绿按钮」误判成 1.18:1，忽略 alpha 会把 20% 透明青绿气泡当成实心
   （这类假阳性我踩过两次，审计器本身也要被验证）。
2. **横向溢出**：1280 / 768 / 390 三个宽度都不允许 `scrollWidth > clientWidth`。
3. **双主题**：深、浅各审一遍。
4. 输出 `ui-dark.png` / `ui-light.png` 供人眼复核。

## 4. 改样式的注意事项

- **不要给 iframe 高度加 transition**：高度变化会触发 ResizeObserver 重测，过渡期间
  持续上报新高度，两者叠加成无限增长的抖动（实测每 100ms 涨 2px）。
- **`data-theme` 由两处共同维护**：`<head>` 的引导脚本负责首帧（否则浅色用户会先
  看到一帧深色），页面脚本负责按钮交互。两处共用同一个 `localStorage` 键。
- **新增文案必须进 4 种语言的字典**（zh / zhHant / en / pt）；`data-i18n-title`
  也由 `applyI18n` 统一应用（这个分支曾经缺失，导致悬浮提示永远为空）。
- 排版用**版心**（`--measure`，68rem）：宽屏不把长行拉到 1400px。
- 动效必须尊重 `prefers-reduced-motion`，已在全局兜底。
